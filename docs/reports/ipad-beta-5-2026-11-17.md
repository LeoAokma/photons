## What to Test / 更新日志

iPad update / iPad 内容更新 — 0.1.0 (5)

English
• A quick start appears once for each new build. Replay contextual red-frame guides with the round Help button beside Import or the panorama HDR switch. Swipe left/right or use Previous/Next; Close is always at the bottom right.
• Guides explain grid selection, every toolbar tool, single-photo swipe navigation and zoom, panorama controls, draggable frame positions, automatic/manual alignment, LCC and export. Alignment options stay expanded.
• New installs follow your device language. Settings offers System default, English and Simplified Chinese; changes apply immediately, including tutorials and adjustment titles.
• Grid taps and multi-selection respond immediately. Selecting/deselecting photos keeps card dimensions stable; explicitly toggling the inspector animates its panel.
• Closing panorama preserves existing thumbnails and recovers missing previews after memory pressure. The panorama histogram sits inside the preview and folds to a button.
• Panorama zoom correctly says it is a low-resolution stitch preview. It no longer starts a detail render that cannot complete.
• Single-photo detail rendering respects Metal texture and memory limits to prevent the 100% zoom simulator crash. Very large sources may use reduced detail resolution, clearly indicated in the UI.
• Exported linear DNG panoramas show their full image dimensions rather than their embedded 512 px preview. The selected 6000 px output was not being replaced with a 512 px image.

Please test tutorial swipes without accidentally moving the photo/panorama, language switching, rapid grid selection, zooming large RAW files, returning from panorama and 6000 px export. Report iPad model, OS version and reproduction steps. Physical-device HDR and memory behavior remain important beta feedback.
